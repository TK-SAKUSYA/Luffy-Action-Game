# ルフィのアクションゲーム 🏴‍☠️👒

ルフィが主人公のブラウザアクションゲーム「ゴムゴムのバトル！海賊船デッキ大決戦」です。

## 遊び方

- 海賊船のデッキに押し寄せる海兵を倒していきます
- ゴムゴムのピストル：腕が伸びるパンチで攻撃
- ギアセカンド：発動するとスピード＆パワーアップ
- WAVE制で、ボス級の巨漢海兵も登場します
- 肉を取るとHPが回復します
- スコアとKO数が表示されます

キーボードでも、スマホのタッチボタンでも遊べます。

## 使い方

`index.html` をブラウザで開くだけで遊べます。

GitHub Pagesで公開する場合は、リポジトリの Settings → Pages で main ブランチを選択してください。
